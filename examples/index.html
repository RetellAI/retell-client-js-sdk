Retell Web SDK — gateway demo

One page, two flows: start a web call, and live-listen / take over a phone call. Both run on whichever transport the backend picks — the SDK follows the response.
Local testing only. This page sends your API key straight from the browser, which a real integration must never do — mint tokens on your server. Also serve it over http://localhost (e.g. npx serve examples): the mic needs a secure context, and file:// is not one.
